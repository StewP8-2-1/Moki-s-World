# Admin guide

> Status: planned (Phases 3–5). This page will be filled in as the editor is built.

How to use the editor at `/admin.html`:

1. **Log in** with the admin password.
2. **Pick a scene** from the scene switcher in the top bar.
3. **Add an object.** Click or drag an item from the *Add* palette (Painting, Link, Portal, Promo, Text, Decor).
4. **Move and resize it.** Drag the object on the map; drag the corner handle to resize. Arrow keys nudge it, Delete removes it and Ctrl+D duplicates it.
5. **Edit its details** in the inspector on the right: title, description, link URL, image and so on.
6. **Preview your changes.** *Preview as player* shows the draft without making it public.
7. **Publish.** Changes go live only when you press **Publish**. Use *Versions* to roll back to an earlier version.
